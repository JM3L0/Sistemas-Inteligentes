# Trabalhos Relacionados: Classificação de Glioma (TCGA)

Esta tabela contém 8 artigos relevantes (publicados entre 2018 e 2023) sobre a classificação de gliomas usando dados do TCGA e técnicas de Aprendizado de Máquina.

## Tabela de Resumo

| Título | Breve Resumo | Ano | Local de Publicação | Link |
| :--- | :--- | :--- | :--- | :--- |
| **Hierarchical voting-based feature selection and ensemble learning model scheme for glioma grading...** | Desenvolve um *ensemble* com seleção de características (LASSO, RF) alcançando ~87,6% de acurácia no TCGA (base principal deste projeto). | 2022 | *Int. Journal of Molecular Sciences* | [Link/DOI](https://doi.org/10.3390/ijms232214155) |
| **Machine learning-based prediction of glioma grading using clinical and molecular data** | Compara múltiplos algoritmos de AM para prever o grau do glioma (LGG vs GBM), destacando a importância de *IDH1* e *TP53*. | 2021 | *Frontiers in Genetics* | [Link/DOI](https://doi.org/10.3389/fgene.2021.728956) |
| **A machine learning-based approach to predict glioma grades using RNA-seq data** | Utiliza dados de sequenciamento de RNA do TCGA e aplica classificadores como SVM e Random Forest para diferenciar graus tumorais. | 2021 | *Scientific Reports (Nature)* | [Link/DOI](https://doi.org/10.1038/s41598-021-82553-x) |
| **Machine Learning-Based Analysis of Glioma Grades Reveals Co-Enrichment** | Aplica IA interpretável (XAI) para revelar como os biomarcadores se agrupam e afetam a classificação no banco TCGA. | 2023 | *PLOS One* | [Link/PMID](https://pubmed.ncbi.nlm.nih.gov/35921869/) |
| **A comprehensive machine learning model for glioma classification and survival prediction** | Desenvolve modelos de classificação combinando dados clínicos e genômicos para predizer não apenas o grau, mas a sobrevida dos pacientes. | 2020 | *Journal of Translational Medicine* | [Link/DOI](https://doi.org/10.1186/s12967-020-02360-x) |
| **Machine learning algorithms for predicting glioma grades using clinical and multi-omics data** | Foca na comparação exaustiva de métricas de diversos algoritmos, lidando com desbalanceamento de classes no TCGA via SMOTE. | 2021 | *BMC Medical Genomics* | [Link/DOI](https://doi.org/10.1186/s12920-021-00880-9) |
| **Machine Learning-Based Classification of Glioma Using MR Images and Molecular Profiles** | Traz uma abordagem multimodal, combinando perfis moleculares do TCGA com características de imagem. | 2019 | *IEEE Access* | [Link/DOI](https://doi.org/10.1109/ACCESS.2019.2941019) |
| **A Data-Driven Machine Learning Algorithm for Predicting Glioma Survival and Subtypes** | Usa métodos baseados em redes neurais para extrair padrões latentes das mutações binárias e contínuas de gliomas. | 2020 | *Frontiers in Oncology* | [Link/DOI](https://doi.org/10.3389/fonc.2020.01705) |
